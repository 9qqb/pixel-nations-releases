# Pixel Nations

**English** · [中文](#中文)

Pixel Nations is a pixel-art grand strategy game for Windows. You watch the world as a god: nations grow, colonize, trade, fight and break apart on historical scenarios or randomly generated maps.

## Download

**[Download the latest installer (beta 0.10.2)](https://github.com/9qqb/pixel-nations-releases/releases/latest)** · [All releases](https://github.com/9qqb/pixel-nations-releases/releases)

- Windows 10/11, 64-bit. The runtime is included; no need to install .NET.
- Run `PixelNations-Setup-0.10.2.exe` and follow the installer. The game appears in the Start menu as **Pixel Nations**.
- The installer is not code-signed yet. If Windows SmartScreen warns you, click **More info → Run anyway**.
- The game starts in Chinese on Chinese systems and in English everywhere else; you can switch the language in Settings.

## What's in the game

- Historical scenarios, including large 1618 and 1700 world maps, plus random maps and a custom map editor.
- Economy, food, population, colonization, diplomacy, subjects (puppets, protectorates, dominions) and civil wars.
- Front-line warfare, navies, straits and sea trade lanes.
- Scenario event editor and flag editor.

This repository only hosts game downloads and release notes. Third-party licenses for the engine and runtime are installed with the game in the `licenses` folder.
